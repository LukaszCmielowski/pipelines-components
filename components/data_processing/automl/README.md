# AutoML

This subcategory contains components in the **AutoML** group:

- [Multimodal Image Data Loader](./multimodal_image_data_loader/README.md): Validate an image manifest, stage images, and write fixed train, tuning, and holdout splits.
- [Tabular Data Loader](./tabular_data_loader/README.md): AutoML Data Loader component.
- [Timeseries Data Loader](./timeseries_data_loader/README.md): Load and split timeseries data from S3 for AutoGluon training.
